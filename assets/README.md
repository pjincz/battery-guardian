# Battery Guardian icon

Generated with the built-in ImageGen tool. The original transparent PNG is
`battery-guardian.png`; the Windows multi-resolution resource is
`battery-guardian.ico` (16, 20, 24, 32, 40, 48, 64, 128 and 256 pixels).

The icon is embedded into the executable and reused by the notification area,
the hidden tray window and the visible terminal window.

Rebuild the ICO from the PNG with `tools/create_icon.ps1` from the project root.
No image-generation service is required to build the application.

## Generation prompt

Use case: logo-brand. Create a polished Windows desktop application icon for Battery Guardian, an energy-efficient CPU process utility. One single centered bold icon on a truly transparent background, square canvas. A rounded upright emerald-green battery silhouette subtly shaped like a protective shield, a short battery terminal at the top, with one large clean white lightning bolt inset. Thick simple geometry, flat vector-like edges, very subtle green shading, excellent contrast and instantly readable when reduced to 16x16 pixels. Icon fills about 85 percent of the canvas, balanced and symmetrical. No text, letters, tiny details, mockups, extra icons, frame, ground shadow or background. Output a single high quality transparent PNG icon.
