# Battery Guardian

Battery Guardian 是一个 Windows 托盘工具，用于将指定程序绑定到 CPU 的能效核（E 核），尝试降低后台程序对高性能核心的占用和能耗。它会在启动时处理已运行的程序，并持续监听新启动的程序；需要限制哪些程序，由你在 `blacklist.txt` 中指定。实际续航收益取决于硬件和使用场景。

**免责声明：本项目几乎全部由 AI 编写，缺乏充分的人工审核，可能存在尚未发现的错误。使用前请自行评估风险；项目不保证节能效果、稳定性或兼容性，使用风险由使用者自行承担。**

## 开始使用

1. 将 `BatteryGuardian.exe` 和 `blacklist.txt` 放在同一目录。
2. 启动程序，并允许 Windows 请求的管理员权限。
3. 在托盘图标的右键菜单中选择 `Edit blacklist.txt`，填写需要限制的程序名并保存。
4. 点击 `Reload blacklist.txt`，对已运行和后续启动的匹配程序应用设置。

默认名单为空，不会限制任何程序。托盘图标可能位于任务栏的隐藏图标区域。

需要 CPU 配备可被 Windows 识别的 E 核；不支持的硬件或配置会跳过绑定，并在日志中说明。

## 配置名单

`blacklist.txt` 使用 UTF-8 编码，每行填写一个 exe 文件名，例如：

```text
# Background applications
example.exe
another-app.exe
```

- 文件名不区分大小写，同名进程都会匹配。
- 空行和以 `#` 开头的注释行会被忽略。
- 不支持完整路径、通配符或行尾注释。
- 保存后点击 `Reload blacklist.txt` 才会生效。
- 清空名单并重新加载，可取消当前规则并尝试恢复原设置。

绑定 E 核可能降低目标程序的性能，建议先从不需要高性能的后台程序开始尝试。

## 日常操作

- **左键点击托盘图标**：显示或隐藏日志窗口。关闭日志窗口只会隐藏窗口，程序仍在后台运行。
- **Edit blacklist.txt**：用记事本打开名单。
- **Reload blacklist.txt**：先恢复之前修改的设置，再加载名单并应用新规则。
- **Exit**：恢复仍在运行的受管进程的原始 CPU 亲和性，然后退出。

成功应用规则后会显示托盘气泡通知，是否可见取决于 Windows 的通知设置。重复启动程序会提示已有实例运行。

请通过 `Exit` 正常退出。强制结束程序、崩溃或断电时，无法保证恢复原设置；设置或恢复失败会记录在日志中。

## 查看日志

日志记录进程启动和规则应用结果，可选择并复制文本。每条记录占一行，`START` 表示进程启动，`AFFINITY` 表示已设置 CPU 亲和性。

`?` 表示信息无法获取，`err=` 和 `perr=` 分别记录进程与父进程的查询错误。短命进程可能在查询前就已退出，信息缺失不一定代表规则应用失败。

## 从源码编译

安装 Visual Studio 或 Build Tools 的“使用 C++ 的桌面开发”工作负载，然后运行：

```bat
build.cmd
```

生成的程序位于 `build\BatteryGuardian.exe`，名单位于 `build\blacklist.txt`。重新构建不会覆盖已有名单。
